Practical 6: Inheritance
Aim
To implement different types of inheritance in C++.
Types demonstrated
1. Single inheritance – Student inherits from Person.
2. Multilevel inheritance – Child inherits from Parent, which inherits from Grandparent.
3. Multiple inheritance – Result inherits from both Academic and Sports.
4. Hierarchical inheritance – Circle and Square both inherit from Shape.
5. Hybrid inheritance – TeachingAssistant combines multilevel/multiple inheritance. Virtual base inheritance avoids duplicate copies of StudentInfo.
How to run in Dev-C++
1. Open Dev-C++.
2. Select File → Open and choose Practical6_Inheritance.cpp.
3. Select Execute → Compile & Run (or press F11, depending on your Dev-C++ version).
4. The output window displays all five inheritance examples.
